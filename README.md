## 📌 Overview
An interactive web-based Number Guessing application built using **Python (Flask)** on the backend and dynamic HTML/CSS on the frontend. The app generates a random number between **1 and 100**, tracking user attempts and giving real-time feedback until the correct number is guessed.

---

## ⚙️ Features
- 🎲 **Random Number Generation:** Dynamic target selection (1–100) per session.
- 💡 **Instant Feedback:** Dynamic hints ("Too High ⬆️" / "Too Low ⬇️").
- 📊 **Attempt Counter:** Tracks total valid guesses per game round.
- 🛑 **Error Handling:** Validates numeric input to prevent application crashes.
